# FloraVerse --- Product & Web Design Specification

## 1. Identitas Proyek

**Nama:** FloraVerse\
**Konsep:** Ekosistem digital untuk berkebun dan bertani\
**Tema lomba:** Innovative Web Solutions for a Smarter Digital Society\
**Subtema:** Shaping Tomorrow Through Digital Innovation

### Positioning

FloraVerse adalah platform web statis yang menggabungkan:

-   Ensiklopedia tanaman
-   Edukasi dan panduan berkebun
-   Komunitas berdasarkan tanaman, metode, dan hobi
-   E-commerce kebutuhan berkebun dan bertani
-   Personal garden / jurnal tanaman
-   Fitur interaktif untuk membantu pengguna memilih dan merawat tanaman

FloraVerse bukan sekadar marketplace, forum, atau ensiklopedia. Konsep
utamanya adalah **digital gardening ecosystem** yang menghubungkan
pengetahuan, komunitas, commerce, dan pengalaman berkebun personal dalam
satu platform.

### Brand Statement

> **FloraVerse --- Satu Dunia, Berjuta Cara untuk Tumbuh.**

Alternatif positioning copy:

> Ruang digital untuk belajar, berbagi, dan tumbuh bersama.

------------------------------------------------------------------------

# 2. Tujuan Website

FloraVerse dirancang untuk membantu masyarakat:

1.  Menemukan tanaman yang sesuai dengan kondisi dan kebutuhan mereka.
2.  Mempelajari cara menanam dan merawat tanaman.
3.  Menemukan komunitas yang memiliki minat serupa.
4.  Mendapatkan kebutuhan berkebun dalam satu tempat.
5.  Mendokumentasikan perkembangan tanaman.
6.  Mendapatkan pengalaman berkebun yang lebih terarah dan menyenangkan.

### Masalah yang Diangkat

Informasi berkebun sering tersebar di berbagai tempat:

-   Informasi tanaman di website berbeda.
-   Tutorial ditemukan di media sosial atau artikel terpisah.
-   Komunitas berada di platform lain.
-   Produk dibeli melalui marketplace umum.
-   Perkembangan tanaman tidak terdokumentasi secara terstruktur.

### Solusi FloraVerse

FloraVerse menyatukan seluruh proses:

> **Discover → Learn → Connect → Shop → Grow**

Pengguna dapat:

> Menemukan tanaman → mempelajari tanaman → mendapatkan perlengkapan →
> bergabung dengan komunitas → menanam → memantau perkembangan → berbagi
> pengalaman.

# 10. Animation

Animasi harus:

-   Cepat

Contoh:

-   Fade in

-   Slight scale
-   Progress animation
-   Button interaction
-   Scroll reveal

Hindari:

-   Heavy parallax
-   WebGL

-   Banyak objek bergerak bersamaan

# 17. Static Website Strategy

Website wajib berupa static website.

Tidak menggunakan backend sungguhan untuk versi lomba.

Semua data menggunakan dummy dataset.

Namun struktur dibuat modular agar secara konsep dapat dikembangkan
menjadi sistem backend di masa depan.

## Teknologi

### HTML5

Untuk struktur.

### CSS

Dapat menggunakan:

-   Tailwind CSS CDN
-   Bootstrap CDN
-   atau CSS custom

### JavaScript

Untuk interaksi, gunakan **jQuery** sesuai aturan lomba.

Jangan menggunakan:

-   React
-   Vue
-   Angular
-   Svelte
-   Next.js
-   Nuxt
-   library JavaScript lain yang bertentangan dengan aturan lomba

### CDN

Framework/library yang digunakan harus berasal dari CDN.

``` html
<!--
Image source:

License:

```

konsistensi visual.

# 31. Filosofi Desain

Prinsip utama:

> **Nature lives in the content. Technology lives in the interface.**

Artinya:

-   Tanaman direpresentasikan melalui ilustrasi dan konten.
-   Teknologi direpresentasikan melalui UI, data, interaction, dan
    personalization.
-   Warna tidak harus hijau hanya karena produknya tentang tanaman.

FloraVerse harus terlihat seperti:

> **produk teknologi modern yang terinspirasi oleh dunia tumbuhan.**

Bukan:

# 34. Batasan Teknis Lomba

FloraVerse harus mengikuti batasan:

-   Maksimal 7 halaman HTML.
-   Minimal 1 halaman.
-   Utamakan 7 halaman.
-   Bahasa utama Indonesia.
-   Istilah Inggris diperbolehkan.
-   Website berupa static website.
-   Data dapat menggunakan dummy.
-   Framework CSS diperbolehkan.
-   Framework/library JavaScript seperti React, Vue, Angular dan
    sejenisnya tidak digunakan.
-   jQuery diperbolehkan.
-   Framework/library yang digunakan harus melalui CDN.
-   Animasi ringan dan smooth.
-   Aset eksternal harus memiliki Open License dan sumber dicantumkan
    pada source code.

# 35. Kesimpulan Produk

FloraVerse adalah:

> **Playful digital gardening ecosystem yang menggabungkan pengetahuan
> tanaman, edukasi, komunitas, commerce, dan personal gardening dalam
> satu pengalaman digital.**

Keunikan utamanya bukan pada satu halaman tertentu, tetapi pada hubungan
antarfitur:

> **Plant Match → Encyclopedia → Plant Journey → Smart Garden Basket →
> Garden Pulse → Community**

Dengan tujuh HTML utama, FloraVerse tetap dapat memberikan pengalaman
yang terasa seperti aplikasi lengkap menggunakan section, modal, tabs,
drawer, dynamic components, jQuery, dan dummy data.
